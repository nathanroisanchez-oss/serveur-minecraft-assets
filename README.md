# serveur-minecraft-assets

Fichiers publics (sons, textures) pour le serveur Minecraft RPG, servis aux
clients via [jsDelivr](https://www.jsdelivr.com/) depuis ce dépôt.

Le dépôt principal (`serveur-minecraft`) est privé -- ce dépôt-ci ne
contient que des assets destinés à être téléchargés publiquement par le
client Minecraft (packs de ressources additionnels), rien de sensible.

## Contenu

- `resourcepacks/cinematique-voix-off/` -- pack de ressources additionnel
  contenant la voix off de la cinématique d'arrivée (son personnalisé
  `rpgplugin:cinematique.intro`). Voir `resourcepacks/cinematique-voix-off.zip`
  pour la version empaquetée servie au client.
